# SVG Diagram for Framer

Create diagrams with local makers or optional AI and insert them into a Framer canvas. AI sends the prompt and a random installation ID to SVG Diagram. See https://svgdiagram.ai/privacy and https://svgdiagram.ai/terms.

Run `bun install --frozen-lockfile --ignore-scripts`, `bun run test`, and `bun run pack`. This plugin is GPL-2.0-or-later.
